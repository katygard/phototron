# UV Tolerance / Phototron repository

Public repository for the data files and code used in UV tolerance and resilience varies dramatically across freshwater organisms (Stemmler et al. 2026). 

KS_LE50calcs.R is the script used to calculate LE50 values and confidence intervals for each individual taxon. The data files used in this script are contained within this repository in the folder taxa-cleandatafiles. 

Note: these data files were manually cleaned from source files for use in the aforementioned R script! Original source files can be obtained by contacting Katy. Note that each data file here has a column labeled "survival" even though response variable varies by taxon.
